수집하는 정보

클린 영상 다운로더 Chrome 확장 프로그램은 개인정보, 방문 기록, 계정 정보, 쿠키, 비밀번호를 수집하거나 저장하지 않습니다. 분석 도구와 광고 추적기도 사용하지 않습니다.

링크 처리 방식

사용자가 우클릭 메뉴나 확장 아이콘을 직접 선택했을 때 현재 탭의 영상·오디오·직접 미디어 주소만 일시적으로 확인해 Chrome 다운로드를 시작합니다. 해당 주소와 페이지 내용은 저장하거나 개발자 또는 제3자의 서버로 전송하지 않습니다.

권한 사용 목적

  • contextMenus: 페이지·링크·영상·오디오 우클릭 메뉴를 제공합니다.
  • notifications: 다운로드 시작 또는 지원 불가 상태를 알립니다.
  • downloads: 사용자가 선택한 미디어를 Chrome 다운로드로 저장합니다.
  • activeTab·scripting: 사용자 동작 직후 현재 탭에서만 video·audio 요소와 직접 미디어 주소를 확인합니다.

제3자 제공 및 판매

확장 프로그램은 사용자 데이터를 수집하지 않으므로 제3자에게 제공하거나 판매하지 않습니다.

Premiere Pro 플러그인

Premiere 플러그인은 사용자가 입력한 영상 링크를 운영자 서버로 전송하지 않습니다. 직접 MP4·WebM·MOV 주소를 입력하면 해당 원본 서버에서 사용자의 컴퓨터로 바로 내려받습니다. 영상 페이지 링크는 클린 영상 다운로더 데스크톱 앱을 로컬에서 호출하며, 로컬 작업 상태와 완성 파일을 현재 Premiere 프로젝트로 가져오는 데만 파일 접근 권한을 사용합니다. 다른 문서나 미디어를 수집·업로드·분석하지 않습니다.
