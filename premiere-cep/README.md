# 클린 비디오 스튜디오 — Premiere 올인원 플러그인

클린 영상 다운로더 데스크톱 앱을 설치하거나 실행하지 않아도 됩니다. 플러그인이 첫 링크 작업 때 운영체제에 맞는 `yt-dlp`와 `ffmpeg`를 GitHub 릴리스에서 사용자 폴더로 자동 준비합니다.

## 설치

- Windows: 압축을 푼 뒤 `install-windows.bat` 실행
- macOS: 압축을 푼 뒤 `install-mac.command` 실행
- Premiere를 다시 시작하고 `창 > 확장 기능(레거시) > 클린 비디오 스튜디오` 선택

## 기능

- YouTube·TikTok·Instagram·Vimeo·TVCF 등 yt-dlp가 지원하는 링크 다운로드
- Chrome/Edge 로그인 쿠키 선택 사용
- 지정 프로젝트 빈에 정리하고 활성 타임라인 V/A 트랙에 삽입
- 클립보드 이미지·파일·직접 미디어 URL·영상 페이지 링크 붙여넣기
- 클립보드 자동 감시
- 현재 Premiere 프레임 PNG/JPG 저장 또는 이미지 클립보드 복사

직접 소유했거나 저장 권한이 있는 콘텐츠에만 사용하세요. DRM, 유료 구독, 계정 권한 및 사이트 접근 제한을 우회하지 않습니다.
