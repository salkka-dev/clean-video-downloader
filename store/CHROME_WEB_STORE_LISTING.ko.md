# Chrome 웹 스토어 등록 문안

## 기본 정보

- 이름: 클린 영상 다운로더 연결
- 요약: 영상 페이지에서 우클릭해 링크를 클린 영상 다운로더 데스크톱 앱으로 보냅니다.
- 카테고리: 생산성
- 홈페이지: https://salkka-dev.github.io/clean-video-downloader/
- 개인정보처리방침: https://salkka-dev.github.io/clean-video-downloader/privacy.html

## 상세 설명

클린 영상 다운로더 연결은 영상 페이지의 링크를 데스크톱 앱으로 빠르게 전달하는 보조 확장 프로그램입니다.

페이지, 링크, 영상 또는 오디오에서 우클릭한 뒤 **클린 영상 다운로더로 받기**를 선택하면 현재 링크가 사용자의 컴퓨터에서 실행 중인 앱으로 전달됩니다. 확장 프로그램 자체는 영상을 내려받거나 계정에 로그인하지 않습니다.

주요 기능:

- 페이지·링크·영상·오디오 우클릭 메뉴
- 로컬 데스크톱 앱으로 한 번에 링크 전송
- 전송 성공 또는 앱 실행 필요 알림
- 방문 기록, 쿠키, 비밀번호를 읽지 않음
- 분석 도구, 광고 추적기, 외부 데이터 서버 없음

클린 영상 다운로더 데스크톱 앱을 먼저 설치하고 실행해야 합니다. 직접 소유했거나 저장 권한을 받은 영상에만 사용하세요.

## 단일 목적 설명

사용자가 선택한 영상 페이지 또는 미디어 링크를 로컬에서 실행 중인 클린 영상 다운로더 데스크톱 앱으로 전달합니다.

## 권한 설명

- `contextMenus`: 사용자가 직접 선택할 수 있는 우클릭 메뉴를 제공하기 위해 사용합니다.
- `notifications`: 링크 전송 성공 또는 데스크톱 앱 실행 필요 상태를 알리기 위해 사용합니다.
- `http://127.0.0.1:18223/*`: 선택한 링크를 사용자 컴퓨터의 데스크톱 앱에 전달하기 위해서만 사용합니다.
