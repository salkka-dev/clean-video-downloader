# Chrome 확장 설치

1. `Clean-Video-Downloader-Chrome.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더를 선택합니다.
5. 영상·오디오·직접 미디어 링크를 우클릭해 **클린 영상 다운로더로 저장**을 선택합니다. 확장 아이콘을 눌러 현재 페이지의 미디어를 찾을 수도 있습니다.

데스크톱 앱은 필요하지 않습니다. 웹페이지에 직접 제공되는 MP4·WebM·MP3 등의 미디어를 Chrome 다운로드로 저장합니다. DRM 또는 영상과 음원이 분리된 스트리밍은 저장하지 않습니다.

Chrome 웹 스토어 정식 배포는 별도 개발자 등록 및 심사가 필요합니다.
