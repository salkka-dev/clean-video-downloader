# Chrome 웹 스토어 등록 문안

## 기본 정보

- 이름: 클린 영상 다운로더
- 요약: 영상·오디오·직접 미디어 링크를 우클릭해 Chrome에서 바로 저장합니다.
- 카테고리: 생산성
- 홈페이지: https://salkka-dev.github.io/clean-video-downloader/
- 개인정보처리방침: https://salkka-dev.github.io/clean-video-downloader/privacy.html

## 상세 설명

클린 영상 다운로더는 웹페이지에 직접 제공되는 영상·오디오 파일을 Chrome에서 저장하는 독립 확장 프로그램입니다.

페이지, 링크, 영상 또는 오디오에서 우클릭한 뒤 **클린 영상 다운로더로 저장**을 선택하면 현재 탭에서 직접 미디어 주소를 확인해 Chrome 다운로드를 시작합니다. 확장 아이콘을 눌러 현재 페이지의 미디어를 찾을 수도 있습니다.

주요 기능:

- 페이지·링크·영상·오디오 우클릭 메뉴
- Chrome 다운로드로 직접 저장
- 현재 탭에서 사용자가 선택한 미디어만 확인
- 다운로드 시작 또는 지원 불가 상태 알림
- 방문 기록, 쿠키, 비밀번호를 읽지 않음
- 분석 도구, 광고 추적기, 외부 데이터 서버, 데스크톱 앱 연결 없음

웹페이지가 직접 제공하는 MP4·WebM·MP3 등의 미디어를 지원합니다. DRM 또는 영상과 음원이 분리된 스트리밍은 지원하지 않습니다. 직접 소유했거나 저장 권한을 받은 영상에만 사용하세요.

## 단일 목적 설명

사용자가 직접 선택한 현재 탭의 영상·오디오·미디어 링크를 Chrome 다운로드로 저장합니다.

## 권한 설명

- `contextMenus`: 사용자가 직접 선택할 수 있는 우클릭 메뉴를 제공하기 위해 사용합니다.
- `notifications`: 다운로드 시작 또는 지원 불가 상태를 알리기 위해 사용합니다.
- `downloads`: 사용자가 선택한 미디어를 Chrome 다운로드로 저장하기 위해 사용합니다.
- `activeTab`: 사용자가 확장 아이콘이나 우클릭 메뉴를 누른 현재 탭에서만 미디어를 찾기 위해 사용합니다.
- `scripting`: 사용자 동작 직후 현재 탭의 video·audio 요소를 확인하고 Blob 미디어 저장을 시작하기 위해 사용합니다.
