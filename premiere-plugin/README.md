# 클린 영상 다운로더 — Premiere Pro 플러그인

영상 링크를 데스크톱 앱으로 보내 다운로드·H.264/AAC MP4 변환을 완료한 뒤, 현재 Premiere 프로젝트에 가져와 활성 시퀀스의 재생 헤드 위치에 자동 삽입하는 UXP 패널입니다.

## 요구 사항

- Adobe Premiere Pro 25.6 이상
- 클린 영상 다운로더 데스크톱 앱 2.4.0 이상
- 직접 소유했거나 저장 권한을 받은 영상

## 설치

1. `Clean-Video-Downloader-Premiere.ccx`를 더블클릭하고 Creative Cloud Desktop의 설치 안내를 완료합니다.
2. Premiere Pro를 다시 연 뒤 `창 → UXP 플러그인 → 클린 영상 다운로더`를 선택합니다.
3. 프로젝트와 시퀀스를 열고 링크, 화질, 트랙을 고른 뒤 `다운로드 → 타임라인 추가`를 누릅니다.
4. 처음 한 번 표시되는 외부 앱 실행 확인에서 클린 영상 다운로더 실행을 허용합니다.

플러그인은 외부 서버로 링크나 파일을 보내지 않습니다. 다운로드와 변환은 데스크톱 앱이 로컬에서 처리합니다.
