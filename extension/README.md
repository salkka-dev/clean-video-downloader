# Chrome 확장 설치

1. `Clean-Video-Downloader-Chrome.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더를 선택합니다.
5. 툴바의 파란색 다운로드 아이콘을 눌러 **현재 영상 저장**을 선택합니다. 영상·오디오·직접 미디어 링크의 우클릭 메뉴도 사용할 수 있습니다.

데스크톱 앱은 필요하지 않습니다. 현재 페이지의 단일 MP4 스트림과 웹페이지에 직접 제공되는 MP4·WebM·MP3 등을 Chrome 다운로드로 저장합니다. YouTube는 페이지에서 제공되는 음성 포함 단일 MP4가 있을 때 저장하며, 영상과 음원이 분리된 고화질 스트림·DRM·유료·보호 미디어는 저장하지 않습니다.

기존 **클린 영상 다운로더 연결**을 설치했다면 삭제하거나 업데이트한 뒤 새 버전 **클린 영상 다운로더 2.4.1**을 사용하세요.

Chrome 웹 스토어 정식 배포는 별도 개발자 등록 및 심사가 필요합니다.
